# Student Assignment Tracker

and
CPAN 324 - Project Development II - Project - By Group 1 - Bolos Bolos, Dustin Nguyen, and Kaynaan Nuur

Student Assignment Tracker is an academic management web app that helps students manage coursework and improve on their academic grades. Students struggle to balance deadlines, especially with weights and grades spanning across many courses, and most advisors have little to no visibility into who is falling behind. This system lets students track courses and assignments, adds deadline prioritization, grade prediction, GPA tracking, course messaging, notifications, and improves outcomes. 

Currently in a work in progress.
